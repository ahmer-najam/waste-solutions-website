# Waste Solutions Website

Marketing site for a Canadian garbage collection company — residential, commercial, recycling, and bulk removal across Ontario.

## Stack

- Vite + React + TypeScript
- Custom CSS (no UI framework)
- Optimized remote imagery with preload + lazy loading

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Customize

Update brand copy, phone/email, service cities, and form handling in `src/App.tsx`. Swap Unsplash URLs for client photography when available.
